02 / SKRIPSI · MACHINE LEARNING & WEB

Sistem Klasifikasi Topik Podcast Berbahasa Indonesia

Membangun aplikasi web yang menentukan topik podcast secara otomatis dari file audio mentah, menggantikan pengelompokan manual yang sebelumnya hanya mengandalkan judul dan deskripsi.

Rincian Implementasi & Metrik:

  • Dataset & Preprocessing: Mengolah 1.120 audio podcast dalam 7 kategori (transkripsi Whisper, case folding, cleaning regex, stopword removal, stemming PySastrawi, dan TF-IDF).
  • Perbandingan Model: Membandingkan Naive Bayes dengan SVM. SVM terbaik dengan akurasi 77,1% dan F1-score 0,77.
  • Integrasi Web Flask: Mengintegrasikan model machine learning ke web app Flask (unggah file audio → hasil klasifikasi otomatis).
  • Metodologi & Pengujian: Menerapkan metodologi CRISP-DM, pemodelan UML & Use Case, serta validasi fungsi utama melalui Black Box Testing.
Whisper (STT) Python Scikit-learn SVM Flask CRISP-DM
03 / PORTOFOLIO SERTIFIKASI LSP GUNADARMA (2025)

Analisis Perilaku Pengguna Ford GoBike

Proyek Business Intelligence dan analisis data eksploratif (EDA) untuk menganalisis pola penggunaan layanan bike-sharing Ford GoBike di San Francisco Bay Area.

Tahapan Analisis & Temuan Bisnis:

  • Data Cleansing: Membersihkan dan menganalisis ±183 ribu data perjalanan (penanganan missing value, eliminasi outlier durasi menggunakan metode Interquartile Range / IQR, dan pembersihan duplikat).
  • Dashboard & Segmentasi: Menyusun visualisasi interaktif segmentasi pengguna berdasarkan tipe akun (Subscriber harian vs Casual Customer), demografi gender, dan frekuensi rute perjalanan antarstasiun.
  • Rekomendasi Bisnis: Menemukan bahwa pengguna wanita hanya ±23% dibanding pria ±75%, lalu merekomendasikan program promo yang lebih inklusif serta paket layanan fleksibel (harian, mingguan, keluarga).
Python Pandas Seaborn Matplotlib Business Intelligence IQR Outlier
